# [[Working memory]]

**(A key part)**

New information comes here. This is a scratch pad and inbox: the externalisation of your unstructured thinking process throughout the day.

- A thought pops into your head while on a walk -> Working memory
- Taking notes while listening to someone or watching a video -> Working memory
- Working on something and need to hold some information for 2 minutes -> Working memory

The idea is:

**It's very low friction**: No decisions need to be made to capture the information. Worry about processing into structure later.

**Regularly emptied**: You'll sort it later into long-term storage or just delete it. It should be emptied at some point every day or so

**Unstructured**: It's just a scratch pad so don't worry structure. 

Once a day, when you have time, you can triage this information and move notes into a more structured, long-term note.

This means you capture more and don't worry about organisation in the moment. Your brain can relax that nothing needs to be remembered, as it's written down here.

The less *friction to capture* there is, the more you'll reach for it and the fewer things for you to remember (or forget!) yourself

# Week plans

My day-by-day breakdown of my todo lists for the week with a header for each day. Some people like Daily Notes but I prefer a week scope, where I can easily move items across days and see ahead.

I use the ISO week naming convention (i.e. ``2026-W20``) for the note name.

# Organising notes

The file tree structure is a less important aspect of my workflow, seeing as I use [[Keyboard shortcuts|keyboard shortcuts]] to navigate to notes.

I've added an example-vault folder which follows the following structure, based on the [[PARA]] method:
```
Archive/            # Notes that are no longer active or useful
Inbox/              # New notes are created in this directory 
Projects/           # Things I'm responsible for that have an end date
Areas/              # Things I'm responsible for that are on-going
Resources/          # Knowledge about things
2028-W18.md         # Week plan
Working memory.md   # New information comes here
```
See [[Preferences]] for Inbox configuration
