# Default shortcuts

## Jump to or create note
(The biggest efficiency gain)
```
CMD+O
```
 Defaults to the top list item being the previously opened file, for quick back and forth navigation
## Close note
```
CMD+W
```
## New note
```
CMD+N
```

## Create external link
For adding URLs to notes with a label
```
CMD+K
```
## Preferences
```
CMD+,
```

## Toggle read-only mode
```
CMD+E
```

## Standard text formatting
Bold ``CMD+B``; Italics ``CMD+I``, etc
### Writing LaTeX
Inline: $\pi$ -- $\mu$ -- $2^8 = 256$ 

In a centralised box:
$$2\pi r = \text{circumference of a circle}$$
# Custom shortcuts
Shortcuts I've configured via ``Preferences > Hotkeys``

# Split right
Very useful for looking at multiple notes at once
```
CMD+]
```
## Add internal link
A huge part of Obsidian is about linking notes together
```
CMD+L
```
## Move line up/down
```
CMD+UP/DOWN
```
## Toggle left sidebar
```
CMD+[
```
# Graph view - Open local graph
View the relationships between the current note and others via internal links
```
CMD+SHIFT+G
```
## Toggle right sidebar
Mainly used for viewing note heading outlines in large notes
```
CMD+'
```
